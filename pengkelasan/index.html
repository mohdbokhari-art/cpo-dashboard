Data carian · muat naik Excel atau JSON

1Tukar Excel ke Parquet / JSON

Pilih fail Excel keputusan pengkelasan (contoh: SKR.xlsx). Lajur wajib: nama produk, siri permohonan, nama syarikat. Semua lajur lain turut dipaparkan dalam maklumat penuh. Muat turun hasilnya sebagai Parquet (disyorkan untuk data besar) atau JSON.

2Muat naik Parquet / JSON

Guna fail Parquet atau JSON yang telah ditukar sebelum ini. Jauh lebih ringan dan cepat dimuatkan berbanding Excel. Parquet dari Python (pandas / pyarrow) juga boleh digunakan, asalkan ada lajur nama produk, siri permohonan dan nama syarikat.
